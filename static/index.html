Agent architecture

        
Collect synthetic evidence locally → one LLM synthesis call → deterministic guardrails → human approval → mock channel post → independent verification.

      

      

        
About / safety

        
All telemetry is synthetic. Tool outputs are redacted before model context. Rules override model proposals; posting requires operator approval, uses idempotency, and is independently verified. No OTP or CAPTCHA automation is used.
